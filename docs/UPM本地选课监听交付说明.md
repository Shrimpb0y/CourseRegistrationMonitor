用户已澄清 FE 指 Free Elective，与系统 EL 为同一含义。目标课程应选择 ELECTIVE COURSE（EL），系统选项值为 `EL`。实际课程注册弹窗中另外观察到 COMPULSORY COURSE（YW）、AUDIT COURSE（AU）和 COMPULSORY AUDIT COURSE（AW）。

课程性质配置已确定为 `EL`，不再作为待核实条件。自动流程应明确选择该选项，并在注册成功后核对已注册列表中的课程性质。用户的术语澄清不改变其余验证状态：课程添加、最终注册及成功回查仍未完成实测。

## 2 已验证的页面流程

### 进入课程注册区

用户在 Codex 内置浏览器中自行登录后，已成功读取学生页面。主页面地址为 `/smp/action/main/indexSmpStdSetup`。页面通过 `topFrame` 和 `contentFrame` 两个 frame 分别承载顶部导航和业务内容。

从 Menu 进入 MyRegister，业务页面为 `/smp/action/portal/student/myregistra/courseRegistraSetup`。该页面可读取待注册列表、已注册列表和 LECTURE/LAB SCHEDULE 查询入口。

### 查询课程和可选时间

1. 在 COURSE REGISTRATION 中点击 SELECT OTHER COURSE。
2. 在 List of Courses 弹窗中选择 ALL FACULTIES 和 ALL DEPARTMENT。学院变化会异步重建部门控件，应等待选项和课程列表加载后再继续。
3. 按 COURSE CODE 查询 LPD2107，确认结果名称为 GENERAL GERMAN LANGUAGE I。
4. 勾选该行后，页面展开课程性质及 Lecture Time 下拉选项。已读取到目标时间 `ISNIN(10.00-12.00TGH),RABU(9.00PG)`，对应值为 `I10-12,R09`。
5. 本次检查随后取消勾选并关闭弹窗。没有点击确认添加的 OK，也没有点击 REGISTER COURSE(S)。之后待注册列表仍为 NO RECORD。

搜索控件为 `popupFilter-box`；查询结果会异步更新。实现时应使用实际键盘输入或经验证的筛选交互，并等待目标课程行稳定出现。不能输入后立即读取旧列表，也不能把搜索框中的 Enter 默认当作查询操作；本次 Enter 曾关闭弹窗。

### 查询教学班余量

1. 在 MyRegister 中进入 LECTURE/LAB SCHEDULE。
2. Course Code 输入框 `txtCC1` 为只读字段，需要点击旁边的课程选择图标。
3. 在课程选择弹窗按课程代码查询 LPD2107，点击该行的选择图标，将其设为查询条件。
4. 点击 Search，读取 Lecture schedule 表。
5. 定位课程 LPD2107、Lecture Group 1、时间 I10-12 与 R09 的行。
6. 读取 QUOTA、NO. OF STUDENT REGISTERED、NO. OF QUOTA AVAILABLE 和 AVAILABLE。此次结果分别为 29、29、0、0。

该查询页直接提供班级及余量信息，适合作为监听来源。不能通过反复尝试添加课程来替代查询，也不能将“课程出现在可选目录”视为有空位。

### 注册流程的页面说明

页面说明：选中的课程在仍有名额时可被临时保留，用户需在 10 分钟内点击 REGISTER COURSE(S) 完成注册；逾期未注册的课程会被移出待注册列表，名额重新开放。该说明已读取，但本次没有实际验证临时保留与提交过程。

## 3 本地运行方案

初版已实现 Node.js 本地后台进程与本机管理页面，使用新版 Puppeteer Core 驱动本机 Edge。用户手动登录独立的本地浏览器会话，程序查询名额；开启自动选课后按已确认条件执行添加、注册和回查。程序不读取或复制现有 Edge 与 Codex 内置浏览器的登录数据。

本地管理页面仅监听回环地址，例如 `127.0.0.1`。课程配置、浏览器配置目录、状态记录和日志保存在本机；使用桌面通知和本地声音提醒。运行期间仍需向 UPM 官方网站发送登录、查询及选课请求。运行软件不应集成云端数据库、远程日志、分析遥测或第三方消息推送。

推荐先使用浏览器自动操作完成适配验证。若后续确认学校查询接口、会话和请求参数，再评估直接请求方案。已观察到的页面路由不能被当作已经验证的余量 API 或注册 API；目前尚未抓取并确认这些接口。

### 建议监听策略

初始查询间隔建议设为 30 秒，并提供本地可调整配置；这是设计建议，不是学校公布的允许频率。请求串行执行，上一轮未结束时不启动下一轮。遇到网络失败、访问限制或服务器错误时逐步延长间隔，避免快速重试。

学校登录失效时进入“需要重新登录”状态并本地提醒，恢复登录后先重新验证课程和班级。电脑重启后可以自动启动后台程序，但不得假定会话仍有效。电脑须保持开机、联网且不进入睡眠；锁屏本身可允许后台继续运行，仍需实测。

### 监听状态与操作

| 状态 | 判定与下一步 |
| --- | --- |
| 等待登录 | 登录页出现或业务查询失效，提醒用户重新登录 |
| 配置检查 | 确认课程、班级、时间及性质 EL 与目标一致 |
| 监听中 | 精确匹配目标班级，读取本轮余量 |
| 名额已出现 | 余量字段出现正值，重新查询并检查选课条件 |
| 添加处理中 | 防止重复任务；确认课程性质、完整时间及班级 |
| 注册处理中 | 在临时保留期限内执行最终注册，不重复提交 |
| 结果待确认 | 提交超时或反馈不清楚，先查询已注册列表 |
| 成功 | 已注册列表确认目标课程及班级正确，停止该目标监听并本地通知 |
| 需要人工处理 | 时间冲突、课程性质不明确、名额规则不满足或异常无法恢复 |

余量页面包含两个不同字段，其语义差异尚未核实。设计上不能只用容量减已注册人数来替代页面名额。初版要求两个字段同时为正值才会触发自动注册；若两个字段不一致，不提交，需核实可选条件。

## 4 待验证的自动注册步骤

以下为实现要求，不是本次已完成的实测记录。

1. 检查任务配置中的课程性质为 `EL`，对应 ELECTIVE COURSE。
2. 有余量时打开 LPD2107，选择 ELECTIVE COURSE（EL）与 I10-12,R09 时间组合。
3. 确认页面返回的实际 Lecture Group 为 1，检查完整课表冲突和资格限制。
4. 确认添加后待注册列表仅出现目标课程及正确班级，识别剩余保留时间。
5. 点击 REGISTER COURSE(S)，记录反馈；遇到不明确结果先回查，避免重复提交。
6. 在 LIST OF COURSES REGISTERED 中确认 LPD2107、Group 1、时间和课程性质；需要时检查课程注册单。
7. 成功后停止该任务。失败时记录原因并重新判断，不擅自改选其他班级，不退出现有课程。

检查时用户已有其他已注册课程。自动流程应只处理明确指定的目标，任何已有待注册条目都应阻止批量误提交。最终注册按钮可能提交整个待注册列表，应先核对列表范围。

## 5 配置和数据要求

| 配置项 | 建议内容 |
| --- | --- |
| target.courseCode | LPD2107，可改为其他课程代码 |
| target.lectureGroup | 1，可改为该课程的其他班级 |
| target.lectureTime | I10-12,R09，需与所选班级的完整时间一致 |
| target.category | EL，对应 Free Elective 和 ELECTIVE COURSE |
| target.labGroup | 空，初版目标无 Lab；实验班自动注册尚未适配 |
| pollIntervalSeconds | 30，建议初值 |
| run_mode | 先验证监听，验证提交流程后启用自动注册 |
| notification | 本地桌面提示及声音 |
| on_session_expired | 暂停任务，提示手动重新登录 |
| on_success | 停止目标任务并保存本地结果 |

目标保存在本机 `config.json`；新版优先通过管理页搜索课程、加载组别、选择性质和完整时间并保存。改选前停止监听并等待当前查询结束。保存新目标自动清除自动模式；有 Lab 时必须同时选实验班，当前仅监听 Lecture 余量，不支持带 Lab 自动注册。浏览器配置与 Cookie 仅供本地使用，不写入报告或普通日志。启动、统一重启和停止入口见软件目录 README.md。

## 6 软件交付验收标准

| 验收项 | 通过条件 |
| --- | --- |
| 名额读取 | 程序读到的目标班级与人工查询一致；0 名额时不执行添加 |
| 精确匹配 | 只处理 LPD2107 Group 1 和 I10-12,R09，不接受仅周一时间相似的其他班级 |
| 课程性质 | 明确选择 ELECTIVE COURSE（EL），注册后回查课程性质一致 |
| 会话恢复 | 登录过期时暂停并本地通知，重新登录后可恢复 |
| 异步加载 | 等待新列表完成，不读取旧结果或未加载控件 |
| 最终注册 | 真实名额出现且用户仍需要该课时完成一次注册，已注册列表可回查 |
| 重复保护 | 成功后停止；提交超时先回查；重启后不重复注册 |
| 本地运行 | 所有运行存储在本机，无第三方通知和远程日志集成 |
| 故障处理 | 断网与站点错误触发退避，未确认结果不会报告成功 |
| 任务范围 | 不自动退课、改选其他班级或提交其他待注册课程 |

软件目录为 `upm-course-monitor`，包含已安装依赖、UPM 适配器、管理页、配置、启动/重启/停止脚本、README 和测试。21 项逻辑/API/适配辅助测试通过，最近一次全代码行覆盖率约 69%，未达到 80%；受限环境的模拟浏览器测试仍因 Edge 启动退出未通过。2026-10-10 17:52（Asia/Singapore）真实管理页完整流程验收成功：搜索 LPD、加载 5 个组别、保存 LPD2107 Group 1 EL、仅监听读取余量 0、停止。最后查询时间 17:52:44，无错误，自动模式关闭。截图为同目录“UPM课程选择验收.jpg”。真实自动注册仍未验收；服务运行与监听运行需分别查看管理页状态。
